# Project Overview

## SalesFlow CRM

SalesFlow CRM is a Salesforce-based lead tracking and automation project built in a Trailhead Playground.

### Goal

Demonstrate a small but complete CRM workflow: capture sales leads, maintain their status and follow-up information, enforce required data, automatically flag qualified leads, and review pipeline data through reports and a dashboard.

### Scope implemented

- Custom Sales Lead object and navigation tab
- Custom fields for lead contact and tracking information
- Company-required validation rule
- Record-triggered Flow to mark qualified leads as priority
- Sales Lead report grouped by status
- Dashboard with a status donut chart and lead-details table

### Current status

The declarative MVP has been configured and manually tested in Salesforce. This repository currently contains project documentation and screenshots. Actual Salesforce metadata should only be added after retrieving it from the Playground and checking the exported files.
